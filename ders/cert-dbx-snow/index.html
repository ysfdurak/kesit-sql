Databricks Certified Data Analyst Associate

Sınav, Databricks SQL ile veri sorgulama, yönetme ve görselleştirmeye odaklanır. SQL tarafında öne çıkanlar:

  • Unity Catalog: üç düzeyli ad katalog.şema.tablo; GRANT SELECT ON TABLE ... TO ...; managed ve external tablolar.
  • Delta Lake: ACID tablolar, DESCRIBE HISTORY, VERSION AS OF / TIMESTAMP AS OF, OPTIMIZE, ZORDER BY, VACUUM.
  • Veri alma: COPY INTO, CREATE TABLE ... AS SELECT, read_files(), yükleme arayüzü.
  • MERGE INTO ile upsert; INSERT OVERWRITE.
  • Yüksek dereceli fonksiyonlar (dizi/harita): transform, filter, exists, aggregate; explode.
  • Pencere fonksiyonları, PIVOT, QUALIFY, CTE, SQL UDF.
  • Sorgu geçmişi ve profil, SQL warehouse türleri (serverless/pro/classic), panolar, uyarılar (alerts), parametreli sorgular.
-- Databricks SQL
COPY INTO anadolu.satis.orders
FROM '/Volumes/anadolu/ham/siparisler/'
FILEFORMAT = CSV
FORMAT_OPTIONS ('header' = 'true');

MERGE INTO anadolu.satis.products AS t
USING anadolu.ham.fiyat_guncelleme AS s ON t.product_id = s.product_id
WHEN MATCHED THEN UPDATE SET t.price = s.new_price
WHEN NOT MATCHED THEN INSERT *;

SELECT order_id, transform(etiketler, x -> upper(x)) AS buyuk_etiketler,
       filter(etiketler, x -> x LIKE 'k%') AS k_ile_baslayan
FROM anadolu.satis.siparis_etiket;

SELECT * FROM anadolu.satis.orders TIMESTAMP AS OF '2024-12-01';

SnowPro Core

Snowflake'in temel sertifikası mimari ve platform bilgisini SQL ile birlikte ölçer:

KonuBilinmesi gerekenler
MimariÜç katman: depolama (mikro-bölümler), işlem (sanal ambarlar), bulut hizmetleri (meta veri, optimizasyon, güvenlik)
Sanal ambarBoyutlar (XS…6XL), çok kümeli ambar (eşzamanlılık), AUTO_SUSPEND, AUTO_RESUME; ölçek büyütme (up) sorgu hızı, ölçek genişletme (out) eşzamanlılık için
ÖnbelleklerSonuç önbelleği (24 saat, tablo değişmediyse), ambarın yerel disk önbelleği, meta veri önbelleği (ör. COUNT(*))
Mikro-bölümlerOtomatik bölümleme, budama, clustering key ve clustering derinliği
Veri yüklemeStage'ler (user @~, table @%t, named @s), PUT, COPY INTO, Snowpipe, dosya biçimleri
Yarı yapısalVARIANT, v:alan::string notasyonu, LATERAL FLATTEN
Veri korumaTime Travel (AT/BEFORE, UNDROP), Fail-safe (7 gün, yalnızca Snowflake destek), sıfır kopya klon
GüvenlikRBAC, sistem rolleri (ACCOUNTADMIN, SECURITYADMIN, SYSADMIN, USERADMIN, PUBLIC), maskeleme ve satır erişim politikaları
PaylaşımSecure Data Sharing, reader account, Marketplace
