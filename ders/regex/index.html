Desen eşleme: LIKE'tan düzenli ifadelere (REGEX)

REGEXP_LIKE, REGEXP_REPLACE, REGEXP_SUBSTR ve SQL türleri arası farklar.

Uygulamada aç, 6 alıştırmayı çözÜcretsiz, hesap gerekmez, kurulum yok.

LIKE yetmediğinde

LIKE yalnızca iki joker bilir: % ve _. “İçinde rakam geçen e-postalar”, “birden fazla boşluk”, “@ işaretinden sonraki kısım” gibi işler için düzenli ifadeler (regular expressions, regex) kullanılır.

SQL Server'ın eski sürümleriREGEXP fonksiyonları SQL Server 2025 ile geldi. Daha eski sürümlerde LIKE '%[0-9]%' ve PATINDEX ile idare edilir.

Deseni sağlayan satırları bulmak

SELECT customer_id, email
FROM customers
WHERE REGEXP_LIKE(email, '^[a-z]+\.[a-z]+@gmail\.com$');
MySQL'de çift ters bölüMySQL metin sabitlerinde \ kaçış karakteridir; desendeki \. için '\\.' yazılır. Bunun yerine [.] yazmak her SQL türünde çalışır.

Değiştirmek

Ad soyad alanındaki fazladan boşlukları teke indirelim. PostgreSQL'de 'g' bayrağı yazılmazsa yalnızca ilk eşleşme değişir; diğer SQL türleri varsayılan olarak hepsini değiştirir.

SELECT id,
       full_name,
       TRIM(REGEXP_REPLACE(full_name, ' +', ' ')) AS temiz_ad
FROM raw_signups;

Parça almak

SELECT REGEXP_SUBSTR(email, '[^@]+$') AS alan_adi,
       COUNT(*) AS musteri
FROM customers
WHERE email IS NOT NULL
GROUP BY REGEXP_SUBSTR(email, '[^@]+$');
