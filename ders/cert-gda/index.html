Sertifikanın SQL tarafı

Google'ın Coursera'daki veri analitiği sertifikası analiz sürecini altı adımda anlatır: Sor, Hazırla, İşle, Analiz et, Paylaş, Harekete geç. SQL özellikle İşle (temizleme) ve Analiz et adımlarında BigQuery üzerinden kullanılır. SQL türü BigQuery'ye alıp aşağıdaki kalıpları çalıştırabilirsin.

İşle: temizleme kalıpları

AmaçBigQuery kalıbı

Ara sonuçWITH (geçici tablo gibi), CREATE TEMP TABLE betiklerde
SELECT id,
       TRIM(full_name)                AS ad,
       LOWER(TRIM(email))             AS email,
       LENGTH(TRIM(email))            AS uzunluk
FROM raw_signups
WHERE email IS NOT NULL
LIMIT 6;

Analiz et: toplama ve birleştirme

SELECT c.segment,
       COUNT(DISTINCT o.customer_id) AS musteri,
       COUNT(*) AS siparis,
       ROUND(SAFE_DIVIDE(COUNT(*), COUNT(DISTINCT o.customer_id)), 2) AS musteri_basina
FROM anadolu.orders AS o
JOIN anadolu.customers AS c ON c.customer_id = o.customer_id
GROUP BY c.segment
ORDER BY siparis DESC;

Doğrulama alışkanlıkları

  • Temizlikten önce ve sonra satır sayısını karşılaştır.
  • MIN/MAX ile aralık dışı değerleri ara (gelecek tarihli sipariş, negatif fiyat).
  • Kategorik sütunlarda SELECT DISTINCT ile yazım farklarını gör (İstanbul / ISTANBUL / istanbul).
  • Sonucu bir kaynakla (finans raporu) sağla.
