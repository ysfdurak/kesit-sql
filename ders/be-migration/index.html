Migration nedir?

Kesintisiz değişiklik: genişlet–daralt

Çalışan bir uygulamada sütun adını değiştirmek (first_name + last_name → full_name) tek adımda yapılırsa, eski kod yeni şemayla çöker. Bunun yerine değişiklik geriye uyumlu adımlara bölünür:

  1. Genişlet: Yeni sütunu ekle (boş bırakılabilir), eski sütunlara dokunma.
  2. Doldur: Mevcut veriyi yeni sütuna kopyala (büyük tablolarda parça parça).
  3. Geçiş: Uygulama hem eskiye hem yeniye yazsın, sonra yalnızca yeniden okusun.
  4. Daralt: Hiçbir kod eski sütunu kullanmadığında eski sütunu kaldır.
-- 1. Genişlet
ALTER TABLE customers ADD COLUMN full_name TEXT;
-- 2. Doldur
UPDATE customers SET full_name = first_name || ' ' || last_name WHERE full_name IS NULL;
SELECT customer_id, first_name, last_name, full_name FROM customers LIMIT 3;
Büyük tablolarda kilitMilyonlarca satırlı bir tabloda tek seferlik UPDATE veya bazı ALTER işlemleri tabloyu uzun süre kilitler. Doldurma işlemi 5.000–10.000 satırlık partilerle, kısa işlemlerde yapılır.

İyi bir migration betiği

  • Tekrar çalıştırılabilir olsun: IF NOT EXISTS, CREATE OR ALTER.
  • Tek bir mantıksal değişiklik içersin.
  • Canlıya gitmeden önce canlı boyutuna yakın veride denenmiş olsun.
  • Geri dönüş planı olsun (down script veya ileri düzeltme).
