Bir SQL ifadesinin anatomisi

SQL, İngilizceye benzeyen bir dildir. Bir sorgu ifadelerden (statement), ifadeler de yan cümlelerden (clause) oluşur: SELECT ..., FROM ..., WHERE ....

-- Bu bir yorum satırıdır; motor bu satırı okumaz
SELECT name, price          -- hangi sütunlar?
FROM products               /* hangi tablo? */
WHERE category = 'Kitap'    -- hangi satırlar?
ORDER BY price DESC;        -- hangi sırayla? (; ifadenin sonu)

Mantıksal yazım sırası

Yan cümleler şu sırayla yazılır (hepsi zorunlu değildir): SELECT → FROM → JOIN → WHERE → GROUP BY → HAVING → ORDER BY → LIMIT. Sırayı karıştırmak (WHERE'i GROUP BY'dan sonra yazmak gibi) sözdizimi hatası verir.

SELECT category, COUNT(*) AS urun
FROM products
WHERE price > 500
GROUP BY category
HAVING COUNT(*) >= 3
ORDER BY urun DESC;
