Önce veriye bak

İyi bir analist sorgu yazmadan önce veriyi tanır: Hangi tablolar var, kaç satır var, hangi sütunlar boş, tablolar birbirine nasıl bağlı? Veri setleri sayfasında tüm tabloların ilişki şemasını, sütunlarını ve verinin kendisini görebilirsin. Burada aynı keşfi SQL ile yapalım.

Her tabloda kaç satır var?

SELECT 'customers' AS tablo, COUNT(*) AS satir FROM customers
UNION ALL SELECT 'orders', COUNT(*) FROM orders
UNION ALL SELECT 'order_items', COUNT(*) FROM order_items
UNION ALL SELECT 'products', COUNT(*) FROM products
UNION ALL SELECT 'employees', COUNT(*) FROM employees
UNION ALL SELECT 'departments', COUNT(*) FROM departments;

Bir tablodan örnek satırlar

SELECT *
FROM orders
LIMIT 5;

Veri hangi tarihleri kapsıyor?

SELECT MIN(order_date) AS ilk_siparis,
       MAX(order_date) AS son_siparis,
       COUNT(DISTINCT customer_id) AS siparis_veren_musteri
FROM orders;
Keşif kontrol listesiSatır sayısı, tarih aralığı, benzersiz değer sayıları, NULL oranları ve kategorik sütunların değer listesi. Bu beş kontrol, raporlarda yapılan hataların çoğunu daha baştan önler.
