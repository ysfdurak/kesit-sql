İndeks parçalanması

SELECT OBJECT_NAME(ps.object_id) AS tablo,
       i.name AS indeks,
       ps.avg_fragmentation_in_percent AS parcalanma,
       ps.page_count
FROM sys.dm_db_index_physical_stats(DB_ID(), NULL, NULL, NULL, 'LIMITED') ps
JOIN sys.indexes i ON i.object_id = ps.object_id AND i.index_id = ps.index_id
WHERE ps.page_count > 1000
ORDER BY parcalanma DESC;
ParçalanmaÖnerilen işlem (genel kural)

%30 üzeriALTER INDEX ... REBUILD (Enterprise'da ONLINE = ON)

Modern görüşSSD disklerde parçalanmanın etkisi azaldı; birçok uzman artık sık REBUILD yerine düzenli istatistik güncellemesini daha önemli buluyor. Kararı ölçerek ver.
ALTER INDEX ix_orders_date ON dbo.orders REORGANIZE;
ALTER INDEX ALL ON dbo.order_items REBUILD WITH (ONLINE = ON);
UPDATE STATISTICS dbo.orders WITH FULLSCAN;
DBCC CHECKDB (anadolu) WITH NO_INFOMSGS;

Zamanlama: SQL Server Agent

Bakım işleri SQL Server Agent işleri (job) olarak zamanlanır: adımlar, zamanlama ve hata durumunda operatöre e-posta. Topluluğun yaygın kullandığı hazır çözüm Ola Hallengren'in bakım betikleridir. Azure SQL Database'de Agent yoktur; Elastic Jobs veya Azure Automation kullanılır.

SQL türüKarşılık
PostgreSQLVACUUM (ölü satırları temizler, MVCC gereği), ANALYZE (istatistik), autovacuum; zamanlama için pg_cron
MySQLOPTIMIZE TABLE, ANALYZE TABLE; zamanlama için Event Scheduler
OracleOtomatik istatistik toplama (DBMS_STATS), DBMS_SCHEDULER
