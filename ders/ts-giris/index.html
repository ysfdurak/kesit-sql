T-SQL nedir?

Transact-SQL (T-SQL), Microsoft SQL Server ve Azure SQL'in SQL lehçesidir. Standart SQL'e değişkenler, akış kontrolü (IF, WHILE), hata yönetimi (TRY/CATCH), saklı yordamlar ve zengin bir fonksiyon kütüphanesi ekler. Türkiye'de bankacılık, perakende ve kamu sektöründe en yaygın kurumsal veritabanlarından biridir; bu yüzden veri analisti ve veri mühendisi ilanlarında sıkça istenir.

Nesne adları: veritabanı.şema.nesne

SQL Server'da her tablo bir şemaya aittir; varsayılan şema dbo'dur (database owner). Tam ad: anadolu.dbo.customers. Sorgularda şemayı yazmak iyi bir alışkanlıktır.

  • [köşeli parantez]: Boşluk içeren veya ayrılmış kelimeyle çakışan adlar için: [Order Date], [user].
  • N'...': Unicode metin sabiti. Türkçe karakterli değerleri NVARCHAR sütunlara yazarken N'İzmir' biçiminde kullan; yoksa “ş, ğ, ı” gibi harfler bozulabilir.
  • GO: SQL değil, SSMS/sqlcmd'nin toplu iş ayırıcısıdır. Kendisinden önceki komutları ayrı bir paket olarak gönderir. CREATE PROCEDURE gibi bazı komutlar paketteki tek komut olmak zorundadır.
  • İfadeleri ; ile bitirmek isteğe bağlıdır ama önerilir (CTE ve MERGE öncesinde gereklidir).
SELECT @@VERSION AS surum;

SELECT TOP 5 [first_name], [last_name], [city]
FROM dbo.customers
WHERE city = N'İzmir';
AraçlarSQL Server Management Studio (SSMS) en yaygın araçtır; Azure Data Studio ve VS Code eklentisi de kullanılır. Ücretsiz Developer ve Express sürümleriyle kendi bilgisayarında çalışabilirsin. Örnek veritabanı olarak Microsoft'un AdventureWorks ve WideWorldImporters veritabanları popülerdir.
Bu modül nasıl çalışır?T-SQL modülündeki alıştırmalar SQL Server sözdizimiyle yazılır. Tarayıcıdaki motor, SQL Server'ın davranışını taklit eder: TOP, değişkenler, IF/WHILE, TRY/CATCH, geçici tablolar, saklı yordamlar, fonksiyonlar, MERGE, PIVOT ve APPLY çalışır. Hata mesajları SQL Server'ın biçimindedir (ör. Msg 208 Invalid object name).
