Bulutta SQL Server: Azure SQL seçenekleri ve DP-300 konuları

Azure SQL Database, Managed Instance, VM; vCore/DTU, Entra ID, otomatik ayar.

Kapasite

  • vCore modeli: İşlemci çekirdeği, bellek ve depolama ayrı seçilir; serverless katmanı boşta kendini duraklatabilir.
  • DTU modeli: İşlemci, bellek ve G/Ç'yi tek bir paket ölçüyle sunar (Basic, Standard, Premium).
  • Hyperscale: Çok büyük veritabanları ve hızlı ölçekleme için.

Güvenlik ve izleme

  • Microsoft Entra ID (eski adıyla Azure AD) ile kimlik doğrulama; parolasız yönetilen kimlikler.
  • Sunucu ve veritabanı düzeyinde güvenlik duvarı kuralları, private endpoint.
  • TDE varsayılan açık; Always Encrypted, dinamik veri maskeleme, satır düzeyinde güvenlik, ledger (değiştirilemez kayıt) tabloları, veri sınıflandırma ve denetim (audit).
  • Query Store varsayılan açık; otomatik ayar (automatic tuning) kötüleşen planı geri alabilir, eksik indeks önerebilir.
  • Zamanlanmış görevler için SQL Agent yerine (Database'de) elastic jobs.

Yüksek erişilebilirlik

Tüm katmanlarda yerleşik yüksek erişilebilirlik vardır; bölgeler arası felaket kurtarma için aktif coğrafi replikasyon ve failover group kullanılır. Otomatik yedekler belirli bir ana geri dönüşü destekler; uzun süreli saklama (LTR) ayrıca yapılandırılır.

SertifikaBu konular Microsoft'un “Azure Database Administrator Associate” sertifikasının sınavında (DP-300) ölçülür. Sınav içeriği zaman zaman güncellenir; resmi çalışma rehberini kontrol et.
