Neden Python?

Analist ve veri bilimciler çoğu zaman veriyi SQL ile süzer ve özetler, sonra Python ile görselleştirir, modeller veya otomatikleştirir. İyi pratik: ağır işi veritabanında yap (filtre, birleştirme, toplama), Python'a yalnızca gereken özet satırları getir.

pandas ile okumak

import pandas as pd
from sqlalchemy import create_engine, text

# Bağlantı adresleri
# PostgreSQL : postgresql+psycopg://kullanici:sifre@sunucu:5432/anadolu
# SQL Server : mssql+pyodbc://kullanici:sifre@sunucu/anadolu?driver=ODBC+Driver+18+for+SQL+Server
# MySQL      : mysql+pymysql://kullanici:sifre@sunucu/anadolu
# SQLite     : sqlite:///anadolu.db
engine = create_engine("postgresql+psycopg://analist:***@db.sirket.local/anadolu")

sorgu = text("""
    SELECT date_trunc('month', o.order_date) AS ay,
           o.channel,
           SUM(oi.quantity * oi.unit_price * (1 - oi.discount)) AS ciro
    FROM orders o JOIN order_items oi ON oi.order_id = o.order_id
    WHERE o.status = 'delivered' AND o.order_date >= :baslangic
    GROUP BY 1, 2
""")
df = pd.read_sql(sorgu, engine, params={"baslangic": "2024-01-01"})
pivot = df.pivot(index="ay", columns="channel", values="ciro")
pivot.plot(kind="line")

Parametre: asla metin birleştirme

# YANLIŞ: SQL enjeksiyonuna açık ve tip sorunları çıkarır
sehir = input()
pd.read_sql(f"SELECT * FROM customers WHERE city = '{sehir}'", engine)

# DOĞRU: parametreli
pd.read_sql(text("SELECT * FROM customers WHERE city = :sehir"), engine, params={"sehir": sehir})
