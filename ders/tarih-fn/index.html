Analistin en çok kullandığı fonksiyonlar

Satış trendleri, kohortlar, büyüme oranları… hepsi tarihle başlar. Tarih fonksiyonları SQL türleri arasında en çok fark gösteren alandır. Aşağıdaki her kod kutusunda SQL türü sekmesini değiştirerek aynı işin nasıl yazıldığını gör.

Haftanın günüDATEPART(weekday, d)EXTRACT(DOW FROM d) / TO_CHAR(d,'D')DAYOFWEEK(d)strftime('%w', d)

SELECT strftime('%Y-%m', order_date) AS ay,
       COUNT(*) AS siparis
FROM orders
GROUP BY strftime('%Y-%m', order_date)
ORDER BY ay;

SELECT date('2024-01-15', '+1 month') AS bir_ay_sonra,
       date('2024-03-15', 'start of month') AS ay_basi,
       date('2024-03-15', '-7 days') AS bir_hafta_once,
       julianday('2024-12-31') - julianday('2024-01-01') AS gun_farki;
Ay sonu tuzağı31 Ocak'a 1 ay eklemek: SQL Server, PostgreSQL, MySQL ve Oracle 2024-02-29 (ayın son günü) verir; SQLite ise taşmayı sonraki aya aktarır ve 2024-03-02 verir. Ay sonu tarihleriyle çalışırken SQL türünün davranışını mutlaka test et.
SQL Server'da DATEDIFFDATEDIFF(month, '2024-01-31', '2024-02-01') sonucu 1'dir; çünkü DATEDIFF geçen tam süreyi değil, aşılan sınır sayısını sayar. Yaş hesaplarken bu fark önemlidir.

Çalışanların işe girişinden bu yana geçen gün:

SELECT first_name, hire_date,
       CAST(julianday('2025-01-01') - julianday(hire_date) AS INTEGER) AS gun
FROM employees
ORDER BY gun DESC
LIMIT 5;
